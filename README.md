# NullWave

> **Private voice communication for public spaces.**

NullWave is a premium wearable engineered for acoustic voice containment. It traps spoken sound waves at the source, allowing confidential voice calls, meetings, and AI voice interactions anywhere in public without eavesdropping or disturbing people nearby.

---

## Features

- **Sound Containment**: Sound-absorbing internal acoustic materials trap your voice inside the mask.
- **Clear Call Quality**: Internal microphones capture voice clearly while rejecting background street and café noise.
- **Silent Bladeless Airflow**: Continuous fresh air circulation keeps you cool without microphone interference.
- **Real-Time Live Translation**: On-device neural translation for seamless multilingual travel.
- **All-Day Comfort**: Soft medical-grade liquid silicone and ergonomic ear loops (88g total weight).
- **Physical Controls**: Dedicated mute, volume, and AI assistant buttons.
- **Waitlist Backend**: Integrated with Firebase Firestore for early access reservation.

---

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion & Lenis Smooth Scrolling
- **Canvas Engine**: 60fps Hardware-Accelerated Image Sequence Scrubber
- **Backend & Database**: Firebase Firestore

---

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
npm run start
```
